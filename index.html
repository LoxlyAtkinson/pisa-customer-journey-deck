Client Walkthrough

PISA Leadership Assessment Portal

A guided customer and admin journey using the actual exported Stitch HTML screens, from first Landing Page through registration, payment, assessment completion, results, and operational oversight.

Four Journeys

The walkthrough separates each person's path.

The same product supports different moments: a new client buying for the first time, a returning client continuing work, a new admin being onboarded, and a returning admin managing the program.

New clientLands, registers, confirms email, chooses PISA, pays, completes or pauses, then receives results and download access.
Returning clientSigns in, uses the Client Dashboard - PISA, resumes saved work, avoids duplicate purchase, and retrieves the report later.
New adminReceives an invite, sets credentials, signs in through the admin route, and lands on the Admin Dashboard.
Returning adminMonitors the dashboard, manages users and assessments, checks analytics, and follows up on payment/report activity.

New Client

A first-time customer always has a next step.

The flow keeps the customer oriented from the first buying decision to the moment they can download the completed result.

LandUnderstand the PISA offer, price, duration, and reason to begin.

DownloadReach the final result and download the report.

Scope Clarity

The current walkthrough stays focused on the signed PISA delivery.

The portal structure supports a broader assessment catalog, but the current build priority is the site, registration infrastructure, PISA assessment logic, gated results, and payment integration after those pieces are tested.

Signed workLanding, registration, email confirmation/recovery, PISA checkout, assessment, resume, results/download, Client Dashboard - PISA, and admin operations.
Next integration stepPayfast should follow once registration, assessment logic, results, and gating are complete and tested.
New workAdditional assessments can be added after the signed PISA scope is complete and separately quoted.
